# FigCraft + мои доработки

Этот репозиторий хранит **только мои доработки** к [FigCraft](https://github.com/storytold/figcraft)
и автоматически собирает из них Windows-версию программы при каждом новом релизе FigCraft.

Сейчас здесь одна доработка: **OKLCH в колорпикере**. В выпадающем списке форматов
(Hex / RGB / HSL / HSB / **OKLCH** / CSS) появляется OKLCH с полями:

- **L** — светлота, %;
- **C** — хрома, % (100% = 0.4, как в CSS: `oklch(62% 64% 260)` = `oklch(62% 0.256 260)`);
- **H** — тон, °.

Значения читаются и записываются в профиле файла (sRGB или Display P3, File ▸ Color profile).
Цвет, который не помещается в охват, подгоняется по алгоритму CSS Color 4: хрома снижается,
светлота и тон сохраняются.

## Как это устроено

```
overlay/      мои файлы — копируются в FigCraft по тем же путям
patches/      несколько строк, которые подключают мои файлы к коду FigCraft
scripts/      apply.sh — копирует overlay/ и накладывает patches/
CUSTOM_VERSION  номер версии моих доработок (увеличить на 1 после изменений)
.github/workflows/build.yml  автосборка
```

Каждый день в 07:17 GitHub проверяет, вышел ли новый релиз FigCraft. Если вышел — скачивает его,
подключает доработки, прогоняет тесты, собирает Windows-версию и публикует её в **Releases**
этого репозитория под именем вида `v0.5.2-custom.1`.

Если обновление FigCraft сломало подключение (разработчики переписали колорпикер), сборка
остановится, на почту придёт письмо от GitHub, а прошлая рабочая версия останется в Releases.
Тогда нужно поправить файл в `patches/` — обычно это пара строк.

## Как скачать готовую программу

1. Открой вкладку **Releases** справа на главной странице репозитория.
2. Скачай `figcraft-…-windows-x64-portable.zip`.
3. Распакуй на флешку и запускай `figcraft.exe`.

## Как запустить сборку вручную

**Actions** ▸ **Build FigCraft + custom** ▸ **Run workflow**. Можно указать конкретный тег
FigCraft (например `v0.5.1`) или поставить галочку `force`, чтобы пересобрать уже вышедшую версию.

## Как добавить новую доработку

1. Новый код — отдельными файлами в `overlay/` (по тем же путям, что в FigCraft).
2. Строки подключения — новым файлом `patches/0002-….patch`.
3. Увеличить число в `CUSTOM_VERSION`.

Сборка запустится сама после сохранения изменений.
